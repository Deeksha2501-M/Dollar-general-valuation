## Overview
Full-scope equity valuation of Dollar General (NYSE: DG), a ~$41B revenue discount retailer,
built as part of an academic finance project at Virginia Commonwealth University.

## Methodologies Used
- DCF Analysis (3 scenarios: Baseline, Upside, Downside)
- Trading Comparables (5 peers: Dollar Tree, Ross, Burlington, Five Below, Ollie's)
- Precedent Transaction Analysis (4 M&A deals)
- Football Field Chart synthesizing all three methods

## Key Assumptions
- WACC: 5.29% (derived via CAPM: Rf 4.14%, Beta 0.31, MRP 5%)
- Terminal Growth Rate: 3%
- Tax Rate: 22%

## Output
- DCF implied share price: $85–$87
- EV/EBIT comps implied range: $88–$205
- Market price at time of analysis: $103.71

## Tools
Microsoft Excel (DCF modeling, sensitivity tables, Football Field chart)
